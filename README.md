## ✨ 주요 기능

- **4레인 낙하형 라이브** (프세카식 네모 막대 노트)
- **3종 노트**: 🟦 탭 / 🟢 홀드(일찍 떼면 MISS) / 🟥 플릭 (쓸어올리기·끊어치기 필수)
- **5단계 난이도**: EASY ~ MASTER (프세카식 수치, 클라이막스 연타 포함)
- **유튜브 재생**: iframe + 0.5초 간격 앵커 시계로 드리프트 보정
- **판정 여유**: 유튜브용으로 PERFECT ±70ms / GREAT ±120ms / GOOD ±170ms
- 시작이 막히면 "▶ 탭해서 재생" 버튼 표시 (직접 제스처 보장)
- 일시정지 메뉴: 계속하기 / 다시하기 / 로비 (Esc 지원)
- 판정 오프셋 캘리브레이션 (🎯 판정 테스트)
- 커스텀 MP3 업로드 플레이 (파형 분석 음악 싱크 채보)
- **원근감 3D 레인**: 위로 좁아지며 모이는 사다리꼴 레인 (프세카 3D 라이브풍)
